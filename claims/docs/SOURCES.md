# Official sources (checked 2026-11-09)

Each URL below loaded the expected page on 2026-11-09. These are citations only, with no summary of what the law says. Statements about state rules on the site must link to one of these (or another official source) and carry a last-reviewed date, and they need attorney review before launch.

Some sites (content.naic.org, ready.gov) block automated tools. An automated link checker may report them as broken when they work in a browser.
