# Flooring Underlayment — Notes (MOC)

> Up: [[Restoration Notes (MOC)]] → [[Flooring (MOC)]]

Situation-based estimating / justification notes for flooring **underlayment,
vapor barriers, and cushion** during insurance restoration scopes. Each note
covers **one situation** = *substrate × flooring type × install method*.

> [!tip] How to expand this topic
> Add a new situation by copying [[Situation Note]] (template), filling the
> frontmatter (`substrate`, `flooring`, `install`) and the body sections, then
> linking it into the matrix below. The tags keep everything queryable even if
> you forget to add a link.
