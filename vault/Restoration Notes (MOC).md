# Restoration Notes (MOC)

Master index for **situation-based estimating / justification notes** used in
insurance restoration scopes. Organized as **Category → Topic → Situation**,
where each leaf note covers **one concrete situation** and its scope /
justification language.

> [!tip] How to expand
> - **New situation** in an existing topic → copy [[Situation Note]], fill the
>   frontmatter + body, link it into that topic's MOC.
> - **New topic** in a category → add a topic MOC (e.g. `Tear-Out (MOC)`) and a
>   folder under that category.
> - **New category** → add a category MOC (e.g. `Water Mitigation (MOC)`) and
>   list it below.

## Conventions
- **One note = one situation.** Keep notes atomic so they're easy to expand.
- Frontmatter carries structured fields (`category`, plus topic-specific fields
  like `substrate` / `flooring` / `install`) and nested tags for querying.
- Body sections are consistent: **Requirement → Why it's required →
  Estimating note → Standards / references → Related**.
